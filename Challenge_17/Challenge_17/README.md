# Challenge 17 - Firebase Auth + Firestore + SASS (CSS Modules)

Este proyecto es una aplicación React que permite a los usuarios registrarse, iniciar sesión (con email o Google), y acceder a una página protegida utilizando:

- 🔐 Firebase Authentication (Email/Password + Google)
- 🗃️ Firebase Firestore para guardar usuarios registrados
- 💅 SASS con CSS Modules
- 📦 Redux Toolkit para manejo del estado global
- 🔄 Navegación protegida con React Router

---

## 📦 Instalación

```bash
npm install
npm install react-redux @reduxjs/toolkit firebase sass react-toastify react-router-dom
npm run dev
